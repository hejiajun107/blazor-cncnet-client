# M3.10 断线/重连提示与状态显示 验收清单

> 范围：连接状态显示（顶栏状态灯 + 底栏 SYSTEM STATUS + 大厅指示）与断线/重连提示（Toast + 聊天横幅）。
> 涉及文件：`ConnectionMonitor.cs`（新增，状态机 + 通知）、`TopBar.razor`（三态状态灯 + 状态文本）、`MainLayout.razor`（顶栏/底栏接线 + Toast）、`Lobby.razor`（顶栏指示 + 断线横幅）、`app.js`（`toast(msg,kind)`）、`app.css`（新增状态样式）。
> 状态：实现完成，主工程构建 **0 警告 0 错误**。
> 说明：自动重连由 `Connection` 层负责（断线后按延迟自动 `ConnectAsync`，超过重连次数上限停止）；`ConnectionMonitor` 仅反映状态并驱动 UI，不干预重连逻辑。

---

## 0. 前置准备（必读）

- 需**真实 CnCNet 网络**或可控服务器以验证断线/重连；纯本地可验证静态状态显示（顶栏默认 OFFLINE）。
- 断线模拟：登录后在系统级断开网络 / 强杀服务器进程 / 长时间无包（约 30s 超时 ×3 次）。重连成功需网络恢复。
- 手动断开：登录后点大厅「离开」或走主菜单退出流程（触发 `Disconnected`）。

## 已知限制

- 重连次数用尽后（`MAX_RECONNECT_COUNT` 超限）`Connection` 停止重连但不再触发 `Disconnected`，客户端会停在 `RECONNECT` 状态；此时需手动重连/重启（后续可加超时降级）。
- 顶栏「延迟」仍为模拟读数（`initReadout`），真实延迟需 CnCNet 协议层补充 PING 回显，不在本里程碑范围。
- 断线瞬间正在进行的对局（房间/游戏）不自动恢复，需用户自行处理。
