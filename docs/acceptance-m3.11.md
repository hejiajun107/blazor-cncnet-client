# M3.11 出口条件：端到端联机对局验收清单

> 范围：checklist **D2 全勾**（登录 → 大厅 → 建/加入房间 → 配置 → 就绪 → 开始 → 隧道下发端口 → 启动游戏）。
> 本里程碑补齐最后缺口：**隧道（TunnelHandler）接入**，实现真实跨网段联机对局的端口下发与 spawn.ini `[Tunnel]` 生成。
> 涉及文件：`Program.cs`（注册 `TunnelHandler` 单例）、`TunnelHandler.cs`（懒实例化已连接自动 `Start`）、`GameRoomService.cs`（隧道选优/端口下发/START/解析/GAME 广播）、`SpawnIniGenerator.cs`（`[Tunnel]` 节）、`GameLaunchService.cs`（透传隧道信息）。
> 状态：实现完成，主工程构建 **0 错误、本次改动 0 新警告**。
> 说明：自动选优逻辑迁移自原版 `TunnelListBox` 评分（`ping² × 负载率`，仅 Official/Recommended）；单人局免隧道。

---

## 0. 前置准备（必读）

- **需要两个客户端实例**（双客户端 A/B）与**真实 CnCNet 网络**（隧道列表下载 + 隧道 `/request` 端口下发需联网）。
- 环境检测需指向已安装的 RA2/YR 游戏本体（地图加载 + 游戏进程启动用）。
- 推荐验收顺序：先 1–4 静态/半联机核对（单客户端即可），再 5 双客户端端到端。

## 已知限制

- 未实现主机在加载页**手动切换隧道服务器**（原版 `CHANGE_TUNNEL_SERVER_MESSAGE` / TNLPNG 交互）；当前为房主创建房间时自动选优、加载页沿用同一隧道。
- `FHSH` 文件哈希校验仍为保留分支（作弊检测，非联机必需）。
- 游戏结束后无结算展示，直接回房间/大厅。
- 隧道选优为**自动**（无选隧 UI）；如需手动指定，后续可在建房对话框加隧道下拉（复用 `TunnelHandler.Tunnels`）。
- **加入者反查兜底**：加入者从 START 提取隧道地址后，需在本端隧道列表按地址反查监听端口；若本地列表缺失该地址（极罕见，官方隧道均含于列表），`TunnelPort=0` → 不写 `[Tunnel]` 节，游戏无法经隧道互联。
