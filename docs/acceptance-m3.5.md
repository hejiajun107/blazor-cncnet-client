# M3.5 建房间 / 加入房间 验收清单

> 范围：`/online/game` 游戏房间页 + 大厅「创建房间 / 加入房间」入口。
> 涉及文件：`GameRoomService.cs`（新增）、`GameLobby.razor`（新增）、`GameRoomNavigation.cs`（新增）、`Lobby.razor`、`LobbyService.cs`、`Program.cs`、`app.css`。
> 状态：实现完成，构建 0 错误。**游戏进程启动（M3.7）未接入**，点「开始游戏」仅广播 START 并提示。

---

## 0. 前置准备（必读）

- 需**至少 2 个客户端**才能完整验证「加入」：客户端 A 建房间，客户端 B 在大厅列表看到并加入。
- 单人也能验证：创建房间 → 进入房间页 → UI/配置/聊天/离开 全流程。
- 网络要求：能连接 CnCNet（登录成功、大厅有玩家在线）。
- 联调可选：若想与真实 CnCNet 客户端互通，需双方地图文件一致（本客户端按 SHA1 校验，缺失会提示）。

## 1. 创建房间流程（客户端 A）

| # | 操作 | 预期结果 | 通过 |
|---|------|---------|------|
| 1.1 | 登录进入大厅 | 房间列表正常刷新，右上角有「创建房间」按钮 | ☐ |
| 1.2 | 点击「创建房间」 | 弹出创建对话框：房间名（默认「xx 游戏房」）、最大人数（2–8）、密码（可选） | ☐ |
| 1.3 | 房间名为空点「创建」 | Toast 提示「请填写房间名」，不跳转 | ☐ |
| 1.4 | 填写房间名（可设密码/不设密码）点「创建」 | 跳转 `/online/game` 游戏房间页；顶部徽章显示「房主 HOST」；短暂出现「正在加入房间频道…」后进入 | ☐ |
| 1.5 | 进入房间后 | 玩家槽位第 1 格显示自己（自选颜色点亮）；房间名、频道名、公开/密码房标识正确 | ☐ |
| 1.6 | 空槽位 | 显示「等待玩家加入…」，虚线样式 | ☐ |

## 已知限制（本次未实现）

- **M3.6**：出生点映射面板、游戏信息面板、GO 打包游戏选项未接。
- **M3.7**：点击「开始游戏」不启动游戏进程，不隐藏窗口；仅广播 START。
- **隧道**：GAME 广播中隧道字段为 `[DYN]` 动态，未接入 TunnelHandler；跨网（不同内网）玩家联机需等 M3.7 隧道。
- **FHSH 文件校验**：已预留分支，未计算/交换文件哈希。
- 房主切地图时若对方缺图，仅聊天黄字提示（不主动下载）。

## 建议验收顺序

1. 单人：按 §1→§2→§3→§8 走通「创建→配置→就绪→离开」。
2. 双客户端：按 §5 验证广播，按 §6 验证加入与同步。
3. 回归：主菜单 → 登录 → 大厅聊天/右键菜单（M3.1–M3.3）、地图预览（M3.4）无回归。
