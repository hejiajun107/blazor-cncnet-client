# M3.7 游戏加载等待页 + 启动游戏 + 窗口隐藏/恢复 验收清单

> 范围：`/online/loading` 对局加载等待页 + `GameProcessLogic` 启动游戏 + `GameLaunchService` 协调 + 宿主窗口最小化/恢复 + `spawn.ini`/`spawnmap.ini` 生成。
> 涉及文件：`GameLaunchService.cs`（新增）、`GameLoading.razor`（新增）、`GameProcessLogic.cs`（Integration）、`SpawnIniGenerator.cs`（Domain）、`GameRoomService.cs`、`GameLobby.razor`、`Program.cs`、`app.css`。
> 状态：实现完成，主工程构建 0 警告 0 错误；探针验证 `IInfiniFrameWindow` 可在作用域解析、`SetMinimized` 生效。

---

## 0. 前置准备（必读）

- 需要**游戏本体文件**就绪（`ClientConfiguration` 环境检测通过、可执行文件存在），否则「开始游戏」会走 `GameProcessLaunchFailed` 错误分支（也属验收项 §5）。
- 建议 **`ClientSettings.ini` 中 `MinimizeWindowsOnGameStart` 保持默认 true** 验证最小化；临时设 false 可验证加载页常驻。
- 双客户端可验证「加入者收到 START 也本地启动游戏」；单人也能验证主机全流程。
