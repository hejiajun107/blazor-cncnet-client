# M3.8 私聊多标签 验收清单

> 范围：大厅私聊多标签中心（会话标签 + 消息历史 + 未读徽章 + 新消息提醒）。
> 涉及文件：`LobbyService.cs`（会话存储/接收接线）、`Lobby.razor`（多标签面板）、`app.css`（`.pm-tabs`/`.pm-msg`/徽章动效）。
> 状态：实现完成，主工程构建 0 警告 0 错误。
> 说明：私聊采用 IRC `PRIVMSG`，仅当对方也在本客户端在线时才能收发；需**至少 2 个客户端**（或与真实 CnCNet 客户端互通）验证接收分支。

---

## 0. 前置准备（必读）

- 双客户端 A/B 登录同一 CnCNet 大厅，进入 `/online/lobby`。
- 单客户端可验证：右键「私聊」建会话、发消息（本方消息入列显示）、多会话标签、关闭/ESC。
- 收消息验证需对方实际回复：B 右键 A → 私聊 → 发送；A 应弹出私聊中心并显示该消息。

---

## 1. 发起私聊（右键菜单）

| # | 操作 | 预期结果 | 通过 |
|---|------|---------|------|
| 1.1 | 玩家列表/聊天用户名右键 → 点「私聊」 | 打开私聊中心面板，标题「私聊中心 PRIVATE MSG」 | ☐ |
| 1.2 | 新建会话 | 标签栏出现该玩家标签（激活态青色），消息区显示「尚无消息，说点什么吧」 | ☐ |
| 1.3 | 再次对同一玩家私聊 | 不重复建标签，直接激活已有会话 | ☐ |
| 1.4 | 连续对 2 个不同玩家私聊 | 出现 2 个标签，各自独立会话 | ☐ |

## 2. 发送 / 消息历史

| # | 操作 | 预期结果 | 通过 |
|---|------|---------|------|
| 2.1 | 激活会话输入消息回车 / 点「发送」 | 消息立即出现在历史（时间 + 昵称「我」金色 + 文本），自动滚动到底 | ☐ |
| 2.2 | 对方回复（客户端 B） | 该会话历史出现对方消息（时间 + 昵称青色 + 文本），自动滚动到底 | ☐ |
| 2.3 | 消息为空点发送 | 不发送、无报错 | ☐ |
| 2.4 | 切换标签 | 各标签消息历史独立、互不串扰 | ☐ |

## 3. 多标签 / 未读提醒

| # | 操作 | 预期结果 | 通过 |
|---|------|---------|------|
| 3.1 | 面板打开且停在会话 A，B 发来消息到会话 C | 自动激活会话 C，消息直接可见 | ☐ |
| 3.2 | 面板打开停在 A，B 发消息到 A | 会话 A 立即追加新消息（激活会话不累积未读） | ☐ |

| 3.4 | 点面板右上 ✕ / 点遮罩 / ESC | 面板关闭；重新打开（如再私聊）会话与历史仍在 | ☐ |
| 3.5 | 未读徽章 | 非激活会话收到新消息时标签显示金色未读数徽章（跳动动画，respect reduced-motion） | ☐ |

## 已知限制

- 私聊接收依赖双方共享连接（对方须在线）；纯发送可在单客户端验证。
- 未接入原版 `PrivateMessageHandler` 的「需共享频道」限制，改为任意在线玩家可收（更宽松）；共享频道过滤可在 M4 完整私聊页时对齐原版行为。
