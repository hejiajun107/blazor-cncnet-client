> 定位：面向测试人员与协作方的项目介绍、运行说明、测试引导与主要规划。

## 项目概括

`blazor-cncnet-client` 是一款基于官方开源客户端 `xna-cncnet-client` 重构的《红色警戒 2 / 尤里的复仇》及其 MOD 联网客户端。相比原版，核心优势在于：在线大厅、房间、游戏启动、自动更新、设置等核心逻辑**完整沿用官方客户端**，联网协议与行为保持一致，玩家昵称、设置、存档可无缝延续，几乎零迁移成本；同时 UI 层全面重做，用现代 Web 技术替代原版 XNA 自绘界面，交互更流畅、信息呈现更清晰，观感与易用性显著提升。

当前为发布候选测试版，已实现：CnCNet 在线登录、大厅聊天、创建/加入房间、游戏启动、私聊、频道管理指令、断线重连；LAN 局域网联机；遭遇战与战役；设置中心、自动更新、统计与日志兜底。核心链路已通过端到端演练，待验收项为 LAN 双端实测、公网更新服务器接入与 Linux 运行验证。

扩展优势：支持运行时多主题与中英双语切换；为 MOD 定制预留通用机制（主题目录、组件可替换、配置化换皮）；架构上更易维护与迭代，为后续新协议、新平台接入留足空间。

项目按三个主要目标推进：**① 同步 CnCNet 客户端功能**——与官方客户端持续对齐，协议与行为保持一致；**② 定制化功能（优先通用性）**——以通用机制支持 MOD 定制，而非针对单一 MOD 硬编码；**③ UI 及其他扩展性**——主题、多语言、动效体系与架构持续扩展。欢迎参与测试，详见下文运行与测试指引。

## 一、这是什么

一款 **《红色警戒 2 / 尤里的复仇》及其 MOD 的联网对战客户端**（CnCNet 平台），是官方开源客户端 `xna-cncnet-client` 的全新重构版：

- **UI 全面重做**：用现代 Web 技术（Blazor + WebView2）替换原版的 XNA 自绘界面，全新科幻 HUD 风格，交互动效丰富。
- **逻辑层完整复用**：在线大厅、游戏启动、更新、设置等核心逻辑全部沿用原客户端成熟实现，不改变游戏本体。
- **目标**：功能上与官方客户端对齐，同时提供现代 UI、多主题、可扩展能力。

> 官方客户端项目：https://github.com/CnCNet/xna-cncnet-client

## 二、当前已实现功能

### 在线（CnCNet）
- 登录：昵称连接（无密码，与 CnCNet 平台一致）
- 大厅：频道列表、聊天、房间列表、玩家列表
- 右键菜单：私聊 / 邀请 / 加好友 / 屏蔽
- 房间：创建/加入、队伍/地图/规则配置、出生点映射、游戏信息面板
- 游戏启动：生成游戏配置 → 加载等待页 → 启动游戏 → 退出后自动恢复客户端
- 私聊：多标签页、消息历史、未读提示
- 频道管理指令：`/kick` `/ban` `/mute` `/voice` `/invite` `/help`
- 断线检测与自动重连提示

### 局域网（LAN）
- 大厅：广播发现、游戏列表、聊天、玩家列表
- 房间：创建/加入、配置、就绪、启动游戏

### 单机
- 遭遇战：地图/模式选择、AI 玩家、队伍配置、随机出生点、游戏选项、观战（Spectator）
- 战役/任务：任务列表（BattleFS 解析）、难度选择、作弊检测
- 地图编辑器 / 更新日志 / 鸣谢 / 关于 入口

### 系统
- 设置中心：显示 / 音频 / 游戏 / 组件 / 更新 / CnCNet / 隐私，读写原生 settings INI
- 自动更新：启动检查、手动检查、下载解压（与原客户端更新协议兼容）
- 统计窗口：对局统计与总统计
- 多语言：中文（默认）/ 英文 UI 切换
- 多主题：主菜单青色 HUD / 内页蓝色系 / 红警原版金×军绿，运行时切换
- 日志与崩溃兜底：Serilog 落盘 `logs/`，异常弹窗提示

## 三、运行环境与如何运行

### 环境要求
| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11 x64（首版） |
| 运行库 | WebView2 Runtime（缺失时客户端会弹出引导安装提示） |
| 游戏 | 红色警戒 2 / 尤里的复仇 或基于 CnCNet 生态的 MOD 目录（含 `Resources`） |
| 显示 | 最低分辨率 1280×720，推荐 1920×1080 |

### 运行步骤（测试者）
1. 拿到完整可运行目录（约 135 MB，`BlazorCncnetClient.exe` + `wwwroot/` + 运行库文件）。
2. **将整个目录放入游戏目录树**：客户端会从可执行文件位置向上查找 `Resources` 目录（最多 3 层）来定位游戏。典型放置：
   ```
   游戏根目录/
   ├─ Resources/            ← 游戏资源（含 ClientDefinitions.ini）
   ├─ game.exe
   └─ 客户端目录/            ← 把发布目录放这里
      └─ BlazorCncnetClient.exe
   ```
3. 双击 `BlazorCncnetClient.exe` 启动。首次进入为环境检测页，确认游戏资源定位成功后进入主菜单。
4. 联机：主菜单 →「多人游戏」→ 输入昵称 → 连接 → 进入大厅。
5. 玩单机：主菜单 →「遭遇战」/「战役」。

> 若提示"未找到游戏资源目录"，请确认放置位置符合上述目录树。

## 四、测试重点（欢迎重点走查）

### 在线主链路（最关键）
1. 登录 → 进入大厅，频道聊天收发是否正常、是否卡顿。
2. 查看房间列表，创建房间、配置地图/规则。
3. 加入他人房间 / 邀请好友。
4. 开始游戏 → 客户端最小化 → 游戏启动 → 对局结束退出 → 客户端恢复并回到房间。
5. 私聊、右键加好友/屏蔽、频道指令（管理员）。

### 稳定性与边界
- 长时间挂在大厅/房间，观察内存与卡顿（高频聊天刷屏）。
- 断网后是否有断线提示与重连。
- 设置修改后重启是否保留（主题、昵称、难度等）。
- 更新流程：设置中心 →「更新」Tab → 立即检查（当前为本地镜像演练环境，公网服务器接入后验证）。

### 单机
- 遭遇战：添加多个 AI、随机出生点、游戏选项保存，开始游戏。
- 战役：任务列表加载、难度选择、启动。

### 反馈时请提供
- 操作步骤（从哪个页面点进去）
- 期望结果 vs 实际结果（截图/录像更佳）
- 崩溃/异常时的 `logs/` 目录下最新日志文件

## 六、主要规划

### 1. 同步 CnCNet 客户端功能
以官方 `xna-cncnet-client` 为基准，功能持续对齐与跟进：

- 补齐并验收剩余功能闭环：LAN 双端联机、加载存档局、DEBUG 线程断言。
- 随官方上游迭代持续同步核心逻辑（在线协议、更新协议、游戏启动参数等），保持与新服务器端兼容。
- 定期对照官方 Release 做功能差异清单，确保无裁剪、无行为偏差。
- 提供从官方客户端到本客户端的迁移指南（账号/设置/存档延续）。

### 2. 定制化功能（优先通用性）
面向 MOD 定制能力，**优先做成通用机制**而非针对单一 MOD 硬编码：

- **主题目录机制**：MOD 通过 `[Themes]` 配置 + 主题目录整体换肤（配色、字体、背景、按钮样式），无需改代码。
- **页面组件可替换**：关键页面（主菜单、大厅、设置等）拆分为可覆盖组件，MOD 可局部定制。
- **`ClientDefinitions.ini` 扩展**：UI 相关配置项（文案、入口、默认主题等）生效，沿用原版配置体系。
- 目标是形成一套"配置即定制"的规范，任何 RA2/YR 系 MOD 都能低成本换皮接入。

### 3. UI 及其他扩展性
- 主题体系扩展：新增风格主题、主题在线包、跟随系统深色模式。
- 多语言扩展：新增语种仅需补充 Resx + 翻译目录，无需改代码。
- 动效体系：动效令牌（时长/缓动）标准化，新页面自动继承设计语言。
- 架构扩展：服务按模块注册，便于接入新在线平台（如其他 IRC/游戏协议）与统计上报。
- 非功能性：性能/内存持续优化、可访问性（reduced-motion、键盘导航）、Windows 之外的平台评估。
