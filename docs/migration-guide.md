# 从原版客户端迁移指南

> 适用对象：正在使用原版 xna-cncnet-client 的玩家/用户。
> 目的：无缝切换到 **blazor-cncnet-client**，尽量保留昵称、好友列表、设置等个人数据，
> 并给出排障与回退方案。新客户端不修改游戏本体、不覆盖原客户端数据，可与原客户端并行使用。
>
> **核心结论（v2026-09-10 修订）**：新客户端与原版客户端**共用同一游戏目录下的数据文件**
> （好友/忽略/最近列表、设置 INI、翻译目录），因此个人数据**自动迁移、无需手动复制**；
> 只需重选主题、核对新 UI 设置即可。

## 1. 迁移准备

1. **版本匹配**：确认新客户端与你的游戏版本（红警2 / 尤里的复仇 及其 MOD）对应。游戏本体无需任何修改。
2. **备份共享数据文件**（防止误操作/误改）：完整复制以下内容到安全位置——
   `Client/` 目录（好友/忽略/最近列表）、`<游戏>/RA2MD.ini`（红警2/尤里，RA1 为 RA1.ini）、
   `Resources/Translations/`（翻译）。需要整体回退时，连同原安装目录一并备份。
3. **新旧可并存**：新客户端使用独立进程与界面，可与原客户端同时安装；但**不建议同时在线**
   （见 §5 并行注意事项，二者共用同一份数据文件）。

## 2. 数据兼容性

| 数据 | 原位置 | 新客户端 | 迁移方式 |
|---|---|---|---|
| 昵称 | CnCNet 账号 = IRC 昵称（无密码） | 登录页输入 | 无需迁移文件，直接输入原昵称 |
| 好友列表 | `<游戏>/Client/friend_list`（每行一个昵称） | 同路径 | **共用文件，零迁移** |
| 忽略列表 | `<游戏>/Client/ignore_list`（每行一个 ident） | 同路径 | **共用文件，零迁移** |
| 最近玩家 | `<游戏>/Client/recent_list` | 同路径 | **共用文件，零迁移** |
| 设置项 | `<游戏>/RA2MD.ini`（红警2/尤里） | 同一文件 + `Resources/UserDefaults.ini` 提供新键默认值 | **共用文件，零迁移**；键名/键值兼容 |
| 翻译语言 | `<游戏>/Resources/Translations/<locale>/Translation.ini` | 同路径 | **共用文件，零迁移**；缺失时自动回退英文 |
| 主题/快捷键 | 原版 XNA 主题配置 | 新主题系统（design tokens / CSS） | 需在设置页**重选主题**；MOD 主题迁移见附录 D Skill |

> 策略：**新旧共用数据文件 + 新键由 UserDefaults 补默认值**，绝不改动原客户端程序本体。
> 新客户端新增的设置键对原版不可见/不影响，可安全并存。

## 3. 首次启动流程

1. 把新客户端解压到游戏目录所在树（能找到 `Resources` 目录的位置），双击 `BlazorCncnetClient.exe` 启动。
2. 进入**设置**：核对游戏目录、分辨率、音量等（默认已自动定位游戏）；在「外观」中**重选主题**
   （原版主题不迁移，新客户端内置主题见 `docs/mod-customization.md`）。
3. 回主菜单 → **在线（CnCNet）** → 登录浮窗输入原昵称连接。
4. 进入大厅：频道聊天 → 房间列表 → 建/加入房间 → 配置队伍/地图 → 启动游戏。
5. 校验：游戏进程正常启动、客户端窗口自动最小化、游戏退出后窗口恢复。
6. 校验数据：进入大厅后好友列表/忽略/最近玩家应已出现（共用 `<游戏>/Client/` 数据，无需导入）。

## 4. 常见问题（FAQ）

- **连接失败 / 卡在连接中**：检查网络与防火墙；CnCNet 服务器使用标准 IRC/游戏端口。查看 `logs/connection.log` 定位 DNS/超时问题。
- **语言显示异常**：确认 `<游戏>/Resources/Translations/<locale>/` 存在；新客户端按系统区域匹配语言，无匹配时回退英文。可在设置页手动切换语言。
- **游戏无法启动**：确认客户端确实放在含 `Resources` 的目录树中、游戏文件完整；查看 `logs/client-*.log`。
- **好友列表为空**：确认 `<游戏>/Client/friend_list` 存在且未被移动/损坏；该文件为纯文本、每行一个昵称，可手工检查。文件损坏时可从备份还原（§1 第 2 条）。
- **启动闪一下就退 / 无反应**：确认已装 WebView2 运行时（Win11 一般内置）；确认 `Photino.Native.dll`、`WebView2Loader.dll` 与 exe 同目录；被杀软拦截时放行或「解除锁定」。
- **更新相关**：自动更新默认需确认，避免误覆盖原客户端。

## 5. 新旧并行注意事项

新旧客户端共用同一份数据文件（`Client/`、`RA2MD.ini`、`Resources/Translations/`）：

- **不建议新旧客户端同时在线**：二者会同时读写好友/忽略/最近列表与设置，可能互相覆盖（后退出者胜）。
- 迁移期建议：以新客户端为主；如需回原版对比，先退出新客户端再开原版，改动数据前先备份。
- 新客户端不修改游戏本体；其新增设置键原版会忽略，不影响原版运行。

## 6. 回退方案

- 保留原客户端目录即可随时回退：新客户端不修改游戏本体、不改原客户端程序数据。
- 新客户端与旧客户端共用 `Client/`、`RA2MD.ini`、`Resources/Translations/`——若迁移期间这些文件被改动
  且需要还原，用 §1 第 2 条的备份覆盖即可恢复原状。
